§ 01 — Matriks Keamanan

Empat pilar. Setiap baris bisa diverifikasi.

Tidak ada janji kosong. Setiap kontrol di bawah disertai perintah yang bisa Anda jalankan sendiri di peladen setelah serah terima.

P-01

Perimeter Zero-Trust

Root dinonaktifkan, akses hanya lewat kunci, setiap paket masuk ditolak kecuali diizinkan secara eksplisit.

Kontrol Status Verifikasi
Login rootdisabledsshd -T | grep permitroot
Pengguna sudo non-rootprovisionedgetent group sudo
Autentikasi SSHed25519 onlysshd -T | grep password
Firewall stateful UFWdeny inufw status verbose
IPS Fail2Banjail: sshdfail2ban-client status

P-02

Edge Reverse Proxy

Nginx dituning untuk konkurensi tinggi, hanya berbicara TLS 1.3, sertifikat diperpanjang tanpa campur tangan.

worker_processes
auto
ssl_protocols
TLSv1.3

P-03

Isolasi Basis Data

MariaDB hanya mendengarkan loopback. Dari internet, port basis data tidak pernah ada.

internet→ ufw 22 · 80 · 443 edge→ nginx :443 app→ php-fpm / node data→ mariadb 127.0.0.1:3306
